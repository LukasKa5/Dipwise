# Device frames

Apple's official product bezels, from https://developer.apple.com/design/resources/ (Product Bezels):
iPhone 18 Pro Max (Silver), iPhone Duo outer display closed in landscape (Star White), Apple Watch Ultra 3
(Natural, Ocean Band Anchor Blue), and iPad Pro 13-inch M5 (Silver). Each has a transparent screen the size of
that device's App Store screenshot. When using them, follow Apple's Marketing Resources and Identity Guidelines:
https://developer.apple.com/app-store/marketing/guidelines/#section-products
