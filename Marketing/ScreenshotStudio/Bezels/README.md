# Device frames

Apple's official product bezels, from https://developer.apple.com/design/resources/ (Product Bezels):
iPhone 18 Pro Max (Silver), iPhone Duo outer display in landscape (Star White), Apple Watch Series 11 46mm
(Space Gray aluminum, Anchor Blue Sport Band), and iPad Pro 13-inch M5 (Silver). The same iPhone and Apple Watch
frames are in the app's asset catalog for the intro, so the intro and the App Store show identical devices. Each has a transparent screen the size of
that device's App Store screenshot. When using them, follow Apple's Marketing Resources and Identity Guidelines:
https://developer.apple.com/app-store/marketing/guidelines/#section-products
